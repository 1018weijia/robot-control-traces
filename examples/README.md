# Examples

Everything here is synthetic and generated by `make_examples.py`; no real conversation, robot or person is involved.

```
input/codex_home/sessions/…/rollout-2026-01-15T09-00-00-….jsonl   cell-queue session (controller script + run dir)
input/codex_home/sessions/…/rollout-2026-01-16T14-00-00-….jsonl   MCP robot tools + an SDK script, transcript only
input/workspace/runs/demo_000/                                     the run directory of the first session
output/                                                            rct.py export of both rollouts
```

Start with the readable reports:

- [output/episodes/2026-01-15_0199c0de_00/episode.md](output/episodes/2026-01-15_0199c0de_00/episode.md)
- [output/episodes/2026-01-16_0199c0de_00/episode.md](output/episodes/2026-01-16_0199c0de_00/episode.md)

The first session was recorded under `/workspace/demo`; the export finds its run directory through
`--remap-path /workspace/demo=input/workspace`. Regenerate inputs and outputs with:

```bash
python3 examples/make_examples.py            # or --out DIR to write elsewhere
```
